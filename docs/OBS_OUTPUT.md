# OBSテキスト出力

ER Boss Tracker JPは、OBS Studioの「テキスト（GDI+）」ソースから直接読み込めるUTF-8テキストファイルを出力します。OBS WebSocketや追加プラグインは不要です。

## 有効化

1. ER Boss Tracker JPで追跡するセーブとキャラクターを選択します。
2. ［OBS出力］タブで［OBSテキスト出力を有効にする］をオンにします。
3. 必要なら［出力先を選択］から専用フォルダーを指定します。
4. OBS Studioで「ソース」の［＋］から［テキスト（GDI+）］を追加します。
5. ［ファイルから読み取り］をオンにし、表示したい`.txt`を選択します。

既定の出力先は次の場所です。

```text
%LOCALAPPDATA%\ERBossTrackerJP\OBS
```

指定したフォルダーでは、下記の同名ファイルをアプリが更新します。既存ファイルとの衝突を避けるため、OBS出力専用のフォルダーを使用してください。

## 出力ファイル

| ファイル | 内容例 | 用途 |
|---|---|---|
| `progress.txt` | `155 / 207 (74.9%)` | 進捗を1行で表示 |
| `defeated.txt` | `155` | 撃破数だけを表示 |
| `remaining.txt` | `52` | 未撃破数だけを表示 |
| `total.txt` | `207` | 総数だけを表示 |
| `percentage.txt` | `74.9%` | 進捗率だけを表示 |
| `latest_boss.txt` | `接ぎ木のゴドリック` | アプリ起動後に新しく検出した撃破ボス |
| `snapshot.json` | JSON | 将来のブラウザソースや外部ツール連携 |

各ファイルはBOMなしUTF-8です。ファイルごとに一時ファイルへ書いてから置換するため、OBSが途中まで書かれた文字列を表示しにくい構成です。

## 固有名詞の言語

［固有名詞の言語（画面とOBS共通）］を切り替えると、`latest_boss.txt`のボス名と、`snapshot.json`内のボス名・地域名が日本語／Englishへ切り替わります。`progress.txt`、撃破数、未撃破数、総数、進捗率などの数値だけのファイルは変わりません。この設定は進捗画面の固有名詞表示と共通です。

## 現在値を再出力

［現在値を再出力］は、セーブファイルの次回更新を待たず、現在読み込まれている進捗をOBS用ファイルへもう一度書き出します。出力先の動作確認や、OBSで参照するファイルを設定した直後の確認に使用します。ボス撃破を擬似的に発生させる機能ではなく、`latest_boss.txt`の内容も現在保持している値のままです。

## `latest_boss.txt`の仕様

- 初回読み込みは比較基準として扱い、既に撃破済みの全ボスを新規撃破として表示しません。
- 同じセーブ・同じキャラクタースロットで、未撃破から撃破へ変化したボスを表示します。
- 新しい撃破がない更新では、最後に検出したボス名を維持します。
- 複数の撃破を同時に検出した場合は、保存データから実際の撃破順を特定できないため、該当ボスを複数行で表示します。
- キャラクターを切り替えた場合とアプリを再起動した場合は空欄へ戻り、次の新規撃破を待ちます。
- 表示言語を切り替えると、保持中のボス名も日本語／Englishへ切り替わります。

## エラー時の動作

出力先へ書き込めない場合、画面のOBS出力状態が［出力エラー］になります。セーブの読み取り、自動監視、WPF画面の進捗は継続し、既存のOBSファイルは可能な限り維持します。

`snapshot.json`にはキャラクター名、レベル、ボス進捗が含まれます。配信や第三者への共有前に内容を確認してください。セーブファイルのパスや生のイベントフラグは出力しません。
